The Palette MCP server exposes read and write tools grouped by the Palette resource they act on. Write tools are gated behind the `--allow-write` startup flag and remain disabled by default. Delete tools additionally require you to type back the resource name to confirm.

| **Area**         | **Read tools**                                                                                                                                             | **Write tools**                                                       |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| Clusters         | `read_clusters`, `read_cluster_status`, `read_cluster_observability`, `read_attached_profiles_to_cluster`, `fetch_pre_cluster_create_schema`               | `create_cluster`, `update_cluster`, `delete_cluster`                  |
| Cluster profiles | `read_cluster_profiles`                                                                                                                                    | `create_cluster_profile`                                              |
| Projects         | `read_projects`                                                                                                                                            | `create_project`, `update_project`, `delete_project`                  |
| Teams            | `read_teams`                                                                                                                                               | `create_team`, `update_team`, `delete_team`                           |
| Users            | `read_users`                                                                                                                                               | `create_user`, `update_user`, `delete_user`                           |
| Packs            | `read_packs`                                                                                                                                               | —                                                                     |
| Registries       | `read_registries`                                                                                                                                          | —                                                                     |
| Cloud accounts   | `read_cloud_accounts`                                                                                                                                      | —                                                                     |
| Edge hosts       | `read_edge_hosts`                                                                                                                                          | —                                                                     |
| Events           | `read_events`                                                                                                                                              | —                                                                     |
