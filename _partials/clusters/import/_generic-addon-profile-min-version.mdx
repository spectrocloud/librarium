:::warning

Deploying add-on cluster profiles on imported clusters with the **Generic** cloud type requires Palette **4.9.x** or
later. On earlier versions, the cluster with the add-on profile imports successfully and continues to report health, cost, and event data, but
packs are never applied. Clusters imported as **AWS IaaS**, **Azure IaaS**, or **GCP IaaS** are not affected on any
version.

:::
