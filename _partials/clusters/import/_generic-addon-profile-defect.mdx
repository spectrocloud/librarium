:::warning

On Palette 4.9.14 and later, clusters imported with the **Generic** cloud type do not deploy add-on cluster profiles.
The cluster imports successfully and continues to report health, cost, and event data, so there is no visible signal of
the failure. Clusters imported as **AWS IaaS**, **Azure IaaS**, or **GCP IaaS** are not affected. Contact
[support@spectrocloud.com](mailto:support@spectrocloud.com) if you are affected.

:::
