**(Upgrades to 4.10.x)** {props.edition} can now rotate the TLS certificate of the in-cluster Zot registry
automatically. Rotation is turned off by default on new installations and upgrades. Do not turn it on during the
upgrade. After the upgrade completes, use the following steps to turn it on.

1. If agent upgrades are paused for any of your clusters, resume them and wait for the Palette agent upgrade to
   complete. Rotation does not work while agent upgrades are paused. Refer to
   [Pause Agent Upgrades](/clusters/cluster-management/platform-settings/pause-platform-upgrades/) for guidance.

2. Set the `<variable-name>` profile variable to `true`.

   {/* TODO(DOC-3290): replace <variable-name> and add where to set it, from Gaurav's screenshot of the toggle. */}

If you leave rotation turned off, the Zot registry certificate is not renewed and eventually expires. Clusters can then
fail to pull images from the registry.
