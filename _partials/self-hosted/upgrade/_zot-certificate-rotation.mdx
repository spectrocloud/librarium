**(Any to 4.10.a+)** {props.edition} can now rotate the TLS certificate of its Zot registry automatically. Rotation
is turned off by default on new installations and upgrades. Do not turn it on during the upgrade. After the upgrade
completes, use the following steps to turn it on.

1. _(Paused agent upgrades only)_ Resume agent upgrades for the clusters where they are paused. Rotation does not work
   while agent upgrades are paused. Refer to
   [Pause Agent Upgrades](/clusters/cluster-management/platform-settings/pause-platform-upgrades/) for guidance.

2. Wait for the Palette agent upgrade to complete on your clusters.

3. Set the `<variable-name>` profile variable to `true`.

   {/* TODO(DOC-3290): replace <variable-name> and add where to set it, from Gaurav's screenshot of the toggle. */}

If you leave rotation turned off, the Zot registry certificate is not renewed and eventually expires. Clusters can then
fail to pull images from the registry.
