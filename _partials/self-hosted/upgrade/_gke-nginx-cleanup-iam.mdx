:::warning

If you are upgrading {props.edition} to 4.9.a on GKE, the principal that runs
`helm upgrade` must hold the following Cloud Identity and Access Management (IAM) permissions so the upgrade can
prune leftover Nginx Role-Based Access Control (RBAC) resources:

- `container.roles.delete`
- `container.roleBindings.delete`
- `container.clusterRoles.delete`
- `container.clusterRoleBindings.delete`

If the upgrade principal is missing these permissions, the upgrade fails to remove the deprecated Nginx RBAC objects.

:::
