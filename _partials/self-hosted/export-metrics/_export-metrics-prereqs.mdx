- The observability stack must be enabled at install or upgrade time. Set `observability.enabled` to `true` in your
  `values.yaml` file. This value is `false` by default.

  ```yaml
  observability:
    enabled: true # false by default
  ```

  If the observability stack is not enabled, the **Metrics** tab is read-only. Upgrade the environment with the value
  set to `true` before you configure export.

- A reachable Splunk Cloud Platform or Splunk Enterprise HTTP Event Collector (HEC) endpoint.

- A Splunk HEC token.

- A metrics index and a logs index that already exist in Splunk.
