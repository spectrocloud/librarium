1. Select **Test Connection** to verify your settings without saving. The test confirms that Splunk is reachable, that
   the token works, and that both indices accept data. If the test fails, the system console reports the reason, such as
   an incorrect index or an invalid token. Correct any reported issue and test again.

2. Select **Save** to apply the configuration.

Export starts automatically within a few seconds. No restart is required.
