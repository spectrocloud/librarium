1. Select **Test connection** to verify your settings without saving. The test sends a single test metric to confirm
   that Splunk is reachable and that the token works. Palette retains nothing from the test. If the test fails, the
   system console reports the reason, such as an incorrect index or an invalid token. Correct any reported issue and test
   again.

2. Select **Save changes** to apply the configuration.

Export starts automatically within a few seconds. No restart is required.
