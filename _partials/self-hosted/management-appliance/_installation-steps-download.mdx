1. Navigate to [Artifact Studio](https://artifact-studio.spectrocloud.com/), Spectro Cloud's artifact download portal,
   and log in. Refer to the <VersionedLink text="Artifact Studio guide" url="/downloads/artifact-studio"/> for
   instructions on how to access and download artifacts.

2. Under **Install {props.iso}**, select the version to install and click **Show Artifacts**.

3. Download the following artifacts.

   | **Artifact**                          | **Description** |
   | ------------------------------------- | --------------- |
   | **Appliance ISO**                     | The slim installer ISO, without an embedded content bundle. You boot each host from this ISO in [Boot Hosts from ISO and Run the Installer](#boot-hosts-from-iso-and-run-the-installer). |
   | **Content bundle (including Ubuntu)** | The {props.version} management cluster components and packs that pair with the **Appliance ISO**. You upload the bundle after you link the hosts, in [Upload Content Bundle to the Leader Host](#upload-content-bundle-to-the-leader-host). |
   | **MOK Key for Secure Boot**           | (Secure Boot only) The Machine Owner Key (MOK) certificate that you enroll on hosts that use Secure Boot. |

   For the components included in the Appliance ISO and content bundle, refer to
   [Artifact Components](#artifact-components).
