For self-hosted {props.version} environments installed with the Palette CLI, you must authenticate to the Spectro Cloud OCI
registry before you start the installation. The Palette CLI reuses the
resulting Docker credentials, so all subsequent image pulls include
the image pull secret.

Complete the following steps on the Linux host from which you invoke the Palette CLI.

1. Save the image pull secret file provided by Spectro Cloud support as `imagepullsecret.json` on the installer host.

2. Authenticate to the Spectro Cloud OCI registry with the image pull secret.

    ```shell
    cat imagepullsecret.json | docker login -u _json_key --password-stdin https://us-docker.pkg.dev
    ```

    The command returns **Login Succeeded** when the credentials are accepted.

3. Start the installation with the Palette CLI. Refer to the
    <PaletteVertexUrlMapper
        edition={props.edition}
        text="installation guide"
        palettePath="/install-palette/install-on-vmware/"
        vertexPath="/install-palette-vertex/install-on-vmware/"
    /> for the full sequence of prompts.

    ```shell
    palette ec install
    ```

    To deploy a self-hosted Private Cloud Gateway (PCG), run `palette pcg install` instead. Refer to the
    [PCG deployment](/clusters/pcg/deploy-pcg/) guides for the full sequence of prompts.

If you do not run `docker login` before starting the installation, the CLI can still complete without the image pull
secret. You can add or rotate the secret afterward from the system console using the [Post-Installation](#post-installation)
steps.
