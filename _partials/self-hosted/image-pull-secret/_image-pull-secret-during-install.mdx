Adding an image pull secret during installation is supported on the following deployment models:

- Helm chart installations
- Palette Management Appliance installations, configured in Local UI as a profile variable
- Palette CLI installations, configured with `docker login` on the installer host

If you skip the secret during installation, you can configure it [post-installation](#post-installation) using the
system console.
