Adding an image pull secret during installation is supported on the following deployment models:

- Helm chart installations
- Palette Management Appliance installations, configured in Local UI as a profile variable

It is _not_ supported for the following deployment models:

- Palette CLI

For unsupported deployments, or if you skip the secret during installation, you must configure it
[post-installation](#post-installation) using the system console.
