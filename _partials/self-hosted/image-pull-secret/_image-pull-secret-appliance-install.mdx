For self-hosted {props.version} environments installed with the
    <PaletteVertexUrlMapper
        edition={props.edition}
        text={props.edition === "vertex" ? "VerteX Management Appliance" : "Palette Management Appliance"}
        palettePath="/install-palette/palette-management-appliance/"
        vertexPath="/install-palette-vertex/vertex-management-appliance/"
    />, you provide the image pull secret in Local UI during Day-0 cluster setup. The secret is added to
the cluster profile as the optional **Image pull secret** profile variable and propagated to every layer in the
infrastructure and add-on profiles that pulls images from Spectro Cloud OCI registries.

Configure the following profile variable in the **Profile Config** step of the cluster creation flow.

| **Profile variable**            | **Description**                                                                                                                                                                                                                                                                                          | **Type**              | **Default**  |
| ------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------- | ------------ |
| **Image pull secret (Optional)** | The image pull secret provided by Spectro Cloud support, encoded in Base64. The value is masked in Local UI. Leave the field blank if your appliance is airgapped and all workload clusters use mirror registries or image swap, or if you plan to add the secret later through the system console.  | Base64 encoded string | _No default_ |

The variable is optional. If you leave it blank, the installation completes and the appliance operates normally; you can
add or rotate the secret afterward from the system console using the [Post-Installation](#post-installation) steps.
