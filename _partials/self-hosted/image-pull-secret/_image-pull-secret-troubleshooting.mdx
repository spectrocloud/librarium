The image pull secret might not propagate to every workload cluster after you configure or rotate it in the
{props.version} system console. Common causes include a cluster that has lost connectivity to the management plane, an airgapped cluster, or a
cluster, or a cluster with **Pause Agent Upgrades** enabled. Affected clusters cannot pull security-hardened images from Spectro
Cloud's OCI registries until you create the secret on each cluster directly.

To identify affected clusters and create the pull secret on them manually, refer to
[System Management](/troubleshooting/system-management) troubleshooting.
