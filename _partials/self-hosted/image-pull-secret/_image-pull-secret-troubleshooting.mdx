The image pull secret might not propagate to every workload cluster after you configure or rotate it in the
{props.version} system console. For example, a cluster that lost connectivity to the management plane might not have the image pull secret. Affected clusters cannot pull security-hardened images from Spectro
Cloud's OCI registries.

To identify affected clusters, refer to
[System Management](/troubleshooting/system-management) troubleshooting.
