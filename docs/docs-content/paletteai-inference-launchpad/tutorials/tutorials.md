Tutorials are lessons that introduce PaletteAI Inference Launchpad by guiding you through a complete, working example
from start to finish. They are learning-oriented and hands-on. You follow each step, learn by doing, and finish with a
result you can build on. If you are new to the appliance, tutorials are a great place to start.

| ----------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| [Connect Claude Code to Your Appliance](./connect-claude-code.md) | A working Claude Code session answered by a model on your own appliance, end to end. |

More tutorials are on the way. In the meantime, the [How-to Guides](../how-to-guides/how-to-guides.md) cover the full
practical path, from [installing the appliance](../how-to-guides/install-the-appliance.md) to
[deploying a model](../how-to-guides/deploy-a-model.md). If you need help getting started,
[contact Spectro Cloud](https://www.spectrocloud.com/contact) to discuss your use case.
